# Employee Data Analytics Dashboard

A polished, production-ready Streamlit application for exploring employee data, cleaning datasets, and generating actionable analytics insights. The dashboard is beginner-friendly, modular, and ready to upload to GitHub.

## Project Overview

This project provides a complete end-to-end analytics workflow for employee data:
- Upload CSV datasets
- Clean and transform records
- Filter and search employees
- View KPIs and interactive charts
- Export cleaned results and reports

## Features

- Home page with an attractive dashboard UI
- Sidebar navigation and theme support
- CSV upload and dataset preview
- Duplicate removal and missing value handling
- Automatic date conversion and column cleanup
- Interactive charts built with Plotly
- Search and filtering by department, gender, salary, age, experience, and joining year
- Advanced analytics such as highest/lowest paid employees, top salaries, department averages, and growth by year
- Export options for CSV, Excel, and summary text files

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Plotly
- OpenPyXL

## Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd Employee_Data_Analytics
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the app:
   ```bash
   streamlit run app.py
   ```
